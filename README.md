# 📊 Superstore Sales Analysis Dashboard

## Project Overview
Analyzed 100+ retail orders to identify sales trends and loss-making regions. Built using Python, Pandas, and Matplotlib.

## 🛠️ Tools Used
- Python, Pandas, Matplotlib
- Google Colab
- GitHub

## 🔍 Key Insights
- South Region generated highest sales
- Furniture category had most loss orders
- 22% orders were in loss - need pricing strategy
